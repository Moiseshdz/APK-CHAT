# ChatLAN Android — Real-Time Messaging Client

Aplicación Android nativa para un sistema de **mensajería en tiempo real sobre red local e Internet**, con soporte de notificaciones mediante Firebase Cloud Messaging.

## Tecnologías

- Android SDK
- Gradle
- Firebase Cloud Messaging (FCM)
- Comunicación en tiempo real

## Funcionalidades

- Cliente de mensajería Android
- Notificaciones push
- Integración con backend de ChatLAN
- Configuración nativa mediante Gradle

## Paquete

`com.chatlan.app`

## Enfoque de portafolio

Este proyecto demuestra experiencia en desarrollo Android, integración de notificaciones y conexión de clientes móviles con sistemas de mensajería.
